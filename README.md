# 泰拉工坊 2.3 · Terra Workshop

面向 Windows 原版 Terraria 的本地桌面辅助工具。把工坊放在副屏，搜索物品、设置数量与词缀，再实时放入正在游玩的角色背包。

> 当前为早期开发版。已验证原版 1.4.5.8 的游戏启动、内容资源加载和连接初始化；多人房间的完整操作仍需实机验证。仓库源码不包含 Terraria 客户端、服务端或游戏安装文件。

[下载 Windows 便携版](https://github.com/haoyunLi/terra-workshop/releases) · [2.3 更新说明](docs/RELEASE_NOTES_2.3.md)

## 2.3 新增

- **基地仓库**：保存基地范围和箱子规则，查看容量与重复物资，按内容批量命名、箱内合并整理、跨箱分类归仓。
- **整理预览**：先查看改名与移动明细，保存本地存档备份后应用。锁定、占用和主动排除的箱子跳过；预览后的变化会阻止覆盖，独立撤销也会检查冲突。
- **回家存包（单人）**：保留快捷栏、收藏物品及自定义预留数量，将可存物资放入匹配箱子；空间不足的物品保留在背包。
- **图标修复**：补齐居民与血月缺图，首领和天界四柱使用真实图标；全量检查图集，并为加载失败增加明确提示。
- **合成目标**：从目标装备展开材料树，选择配方与同类材料，统一计算已有和欠缺材料；可手动加入当前基地仓库扫描快照，显示本地数据支持的首领掉落来源。

仓库写入当前支持原版 **1.4.5.8**。自己的本机多人房间支持箱子扫描、命名、整理、分类与撤销；**多人自动存包尚未启用**。整理前自动备份要求角色与世界均为本地存档。

## 2.2 功能

- **挑战与收藏**：读取 18 项首领和天界四柱的世界进度，展示代表性战利品、当前持有量和手动收藏清单。
- **入住条件**：读取原生条件，区分满足、欠缺和未知，提示解救、商店购买、随机时机与住房的限制。
- **跨仓储搜索**：搜索背包、随身仓储、装备及未启用配装；按需搜索当前世界箱子，查看箱名、坐标、锁定状态和具体槽位。

## 当前功能

- 中文、英文名称与 ID 搜索；分类、收藏、图鉴、属性与本地合成配方。
- 数据库覆盖物品 ID 1–6195，附 6194 个本地图标；一个内部特效占位项无可用图标。物品介绍为属性整理，并非逐字游戏文本。
- 实时物品发放、原生堆叠分槽、词缀选择、背包和仓储编辑、移除指定物品、撤销上一次背包修改。
- 恢复生命与魔力、调整基础上限、无敌、无限魔力、免摔落、返回出生点。
- 城镇居民召唤、移动到身边、自动找房和指定住房。附自然到来条件、欠缺项、位置与附近传送；住房是否合法仍由游戏判定。
- 补给包、常用增益、时间与降雨控制。
- 人物端与本地主机分开连接的架构；多人模式下，NPC、住房和世界操作交由接入的本机主机执行。
- **Boss 与事件**：18 种首领，战斗环境提示、夜间时间准备、重复召唤保护与生命显示；9 类月亮/入侵/史莱姆雨事件开始和结束。
- **常用快捷栏**：最多 8 项，可收藏物品、首领、事件、预设、书签和人物能力；桌面 App 可启用 `Ctrl+Alt+1–8` 全局快捷键，并报告组合键占用。
- **物品预设**：自行编辑清单，或从当前背包生成；批量发放、空间不足回滚、补充已有药水和弹药。
- **传送书签**：按世界记录命名地点、返回死亡位置；检查世界、坐标边界与实心碰撞。
- **自然刷怪控制**：频率和数量上限 0.1–10 倍、暂停自然刷怪、恢复默认；退出世界后重置。
- **本地存档备份**：保存后备份角色与世界，可选挑战前自动备份；文件和清单校验、退出游戏后恢复、覆盖前保护备份。
- **天界四柱**。在困难模式世界开启原生天界事件，显示日耀柱、星旋柱、星云柱、星尘柱的生命、护盾与月亮领主倒计时。
- **副屏操作**。全新分组导航、物品卡片与详情面板、窗口置顶，以及可持久保存的最近浏览物品。
- **配方缺料补齐**。按背包与随身仓储统计材料，选择材料组候选项，将缺少的直接材料批量放入背包。

游戏会限制不兼容的物品、词缀和住房操作。目录中的全部 ID 不代表每个内部占位物品都能正常使用。

## 使用方式

1. 启动泰拉工坊，选择包含 `Terraria.exe` 的游戏安装目录。
2. 如果之前直接从 Steam 启动了游戏，请正常保存并退出，然后从工坊点击「启动游戏」。
3. 单人进入世界，或在多人游戏中选择「主持并开始」，打开自己的世界。
4. 等待工坊显示角色与世界。选择物品，填写数量与词缀，点击「立即获得物品」。

已有存档仍由原版游戏打开，不需要导入导出。普通启动的现有游戏进程不能直接接入。连接在菜单中已建立时，物品按钮会等进入世界后启用。

更新 2.3 后，请正常保存并退出旧版启动的游戏，再从新版启动，以载入新的连接组件。多人世界控制需要在工坊启动的游戏中选择「主持并开始」，并显示本机主机已连接。

备份针对本地 `.plr` 和 `.wld` 文件，不包含地图探索缓存。Steam 云端存档需要先在游戏里移出云端；若角色与世界只有一项位于本地，备份会明确列出包含的文件。多人单槽堆叠遵守原生上限，超出的发放数量会分槽。

## 从源码构建

需要 Windows、Node.js 24+、PowerShell 7+、.NET Framework 4.8，以及合法安装的原版 Terraria 和运行游戏所需的 XNA 环境。

```powershell
npm ci
npm run restore:bridge
npm run build:bridge
npm test
npm run build
npm start
```

`restore:bridge` 从 NuGet 下载固定版本并检查 SHA-256；工具缓存位于忽略的 `.work/tools`。启动器源码已包含在 `bridge/src/launcher`，构建不依赖作者电脑上的其他项目。

```powershell
# 浏览器仅预览界面；实时连接使用桌面 App
npm run dev

# Windows 原生桥接集成测试，使用模拟游戏 API，不操作真实角色或世界
npm run test:live

# 构建完成后生成 Windows 便携版
npm run package
```

便携版输出到 `out/TerraWorkshop-win32-x64`，需保留完整目录。桥接器对应源码和 GPL 许可证随运行时一起打包。

物品数据和图片已经包含在 `public`。`scripts/prepare-data.mjs`、`complete-assets.mjs` 是可选的数据维护工具，需要另外准备其中注明的上游数据目录；普通构建无需运行。
