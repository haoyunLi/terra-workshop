# 泰拉工坊 2.0

保留全物品编辑，新增副屏游玩辅助功能。

- 18 种 Boss 的图鉴、环境提示、自动夜晚准备、重复召唤保护和生命显示。
- 血月、日食、哥布林、雪人军团、海盗、火星、南瓜月、霜月、史莱姆雨启停。
- 8 项常用快捷栏，支持 `Ctrl+Alt+1–8`；快捷键默认关闭，需要在「预设与快捷」中启用。
- 自定义物品预设、从背包创建预设、批量发放失败回滚、补满已有药水和弹药。
- 按世界保存的传送书签与返回死亡位置，含世界和碰撞检查。
- 0.1–10 倍自然刷怪频率/上限、暂停与恢复。
- 角色和世界的本地备份、挑战前自动备份、签名/文件校验及恢复前保护备份。
- 本机主持客户端/服务端分别连接，主机处理 Boss、事件、居民、时间和刷怪控制。
- 补齐背包撤销和居民住房等网络同步；多人模式限制单槽超堆叠。
- 添加启动日志、加载失败提示和渲染错误恢复界面。

## 更新使用

解压完整便携目录，双击 `TerraWorkshop.exe`。正常保存退出旧游戏后，通过新版工坊启动，再进入单人世界或选择「主持并开始」。普通 Steam 启动的游戏进程不会自动载入工坊组件。

本地配置和备份保存在用户数据目录，未上传到仓库。恢复需要先正常退出游戏与本地主机。备份仅包含本地 `.plr` / `.wld`，不含探索地图缓存；云端文件需先移出云端。

13 项自动化测试、生产构建、原生 C# 启动器/桥接器的模拟单人和双进程主持测试、浏览器交互/窄屏测试、桌面 IPC 和真实系统快捷键测试通过。原版 1.4.5.8 的启动与资源路径曾实机验证，并核对本次使用的客户端/服务端 API。新增游戏操作的真实多人房间覆盖仍有限，详见 [VALIDATION.md](VALIDATION.md)。
