# 泰拉工坊 2.1

## 天界四柱

「Boss 与事件」新增「天界四柱」。在困难模式世界中，可一次开启原生天界事件，生成日耀柱、星旋柱、星云柱和星尘柱。面板显示每座柱子的生命、护盾、坐标与击败状态。击败全部四柱后，游戏按原生流程进入月亮领主倒计时。

已有首领、事件、四柱或月亮领主倒计时进行时会拒绝重复开启。普通事件的「结束事件」按钮只处理普通事件。天界事件需要完成挑战，启动前会明确提示最后的月亮领主降临流程。

多人世界由已接入的本机主机处理，客户端显示主机同步的进度。旧版运行组件会提示先保存并退出游戏，再通过新版工坊启动。

## 新界面与图标

- 重新组织侧边导航、连接状态与快捷操作。
- 物品卡片显示类别和数量，详情区集中呈现发放数量、原生堆叠、词缀和目标位置。
- 新的水晶与铁砧图标应用于界面、Windows 程序和桌面快捷方式。
- 新增窗口置顶开关，默认关闭，选择保存在本机。
- 最近浏览记录和按持有数量排序，方便重复查找物品。

## 配方缺料

合成配方显示材料需求、持有数量与缺少数量。材料组支持选择具体候选材料，重复材料合并计算。可将缺少的直接材料一次发到背包，沿用批量发放和失败回滚。

持有量统计背包、猪猪储蓄罐、保险箱、护卫熔炉和虚空保险箱。实际合成仍需满足原版的材料访问与制作站条件。世界箱子和装备槽位不计入这项统计。

## 更新与验证

下载 Windows 便携包后完整解压，运行 `TerraWorkshop.exe`。旧游戏会话需要正常保存退出后从新版工坊启动，才能加载新的天界事件功能。

本版仍为预发布。四柱逻辑已对照本机原版 1.4.5.8 的方法和字段，自动化使用编译后的连接组件及模拟单人、主持客户端和服务端进行验证。真实游戏中的四柱战斗及完整多人同步仍需实机覆盖。详见仓库的验证记录。
