# 泰拉工坊 2.2

## 挑战与收藏

新增独立挑战页，读取当前世界的 18 项首领和天界四柱进度。原版共用的邪恶首领标记、困难模式阶段与无法读取的记录都有明确说明，避免把阶段进度误写为某个首领的独立击杀记录。

展示代表性战利品、图标、当前持有数量和手动收藏状态。收藏清单按世界 ID 与角色名称保存在本机；持有数量与手动收藏互相独立。清单不表示完整掉落概率表，也不会自动替玩家标记击杀。

## 居民入住条件

居民页新增条件与欠缺项，区分已满足、未满足和暂时无法确认。读取游戏原生条件及世界进度，保留解救、购买、随机时机等说明。条件读取不会触发生成或改动住房；住房有效性仍需游戏判定。

显示已有居民的位置、住房坐标与附近传送，原有召唤、移动、治疗和安排住房功能继续保留。

## 跨仓储搜索

按名称、英文名或物品 ID 查找背包、钱币、弹药、装备、随身仓储及未启用配装中的物品。可跳转到可编辑仓储的具体槽位；未启用配装需先在游戏中切换。

按需搜索当前世界的箱子，结果包含箱名、坐标、槽位、数量及可读取的锁定和使用状态，支持分页及传送至附近。箱子搜索只读取物品，不转移或修改箱内物品。切换世界后旧结果失效。

多人模式使用已经接入的本机主机读取世界进度、居民条件和箱子，角色随身仓储仍来自当前玩家。

## 更新方式

完整解压 Windows 便携包，运行 `TerraWorkshop.exe`。先正常保存并退出旧版启动的游戏，再由新版工坊启动，载入 2.2 连接组件。已有角色和世界继续由原版游戏直接打开。

本版仍为预发布。验证使用实际编译的连接组件与模拟单人、本机主持客户端和服务端；原版 1.4.5.8 字段和方法已做只读核对。真实游戏中的新功能与完整多人同步仍需实机覆盖，详见 [验证记录](VALIDATION.md)。
