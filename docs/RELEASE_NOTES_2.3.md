# 泰拉工坊 2.3 · 基地仓库与合成目标

这次更新让家里的物资更容易找到、整理和规划。继续使用原版游戏，无需导入导出存档。

## 基地仓库

- 记录两个角点，保存基地范围；每次最多扫描 128 个箱子、8192 个槽位。
- 查看箱子位置、内容图标、容量、空箱和分散存放的物资。内容未读取的箱子明确标注，不冒充空箱。
- 根据内容或指定分类批量命名，默认保留已有名字，并避开名称冲突。
- 箱内排序合并、跨箱分类归仓。可排除贵重箱子、指定专用分类；容量不足的物资留在原箱。
- 单人模式下，可将背包物资存入基地，保留快捷栏、收藏物品、金币、弹药和自定义数量；装不下的留在背包。
- 先预览真实改名与移动明细，再自动保存、完整备份角色和世界，最后执行。备份失败会停止整理。
- 使用原生物品克隆，检查数量与属性守恒；词缀、收藏及其他属性不因 ID 重建而丢失。
- 应用前检查世界、角色、箱子实例、位置、占用、锁和内容。10 分钟内可独立撤销；操作后有变化时拒绝覆盖。撤销入口在切换页面后保留，退出世界或重开 App 后清除。

## 合成目标

- 按世界和角色保存目标，从任意物品展开递归材料树。
- 手动选择不同配方与同类材料，显示制作站、已有材料和欠缺材料。
- 同一份库存只分配一次；正确计算批量产物与可用于后续分支的余量。
- 可选计入最近一次基地仓库扫描。快照时间明确显示，箱子变化后需重新扫描。
- 已收录的首领掉落会显示来源和世界进度，帮助决定下一场挑战；未知获取路径、循环配方和未选择分支会明确提示。
- 这里只做规划，不自动执行合成或发放物品。多个目标分别计算，不共同预留材料。

## 图标修复

- 修复血月事件的错误物品键，补齐狗狗、猫咪和天后史莱姆，纠正居民兔兔图标。
- 18 个 Boss 改用真实头像，天界四柱改用对应柱体图；挑战收藏页同步使用。
- 重新核查全部物品图集的文件、像素区域和边界，缺失数据或加载失败会显示具名占位。内部物品 6143 没有真实图标，明确标注。

## 支持范围

仓库写入目前仅启用在已核对接口的 **Windows 原版 Terraria 1.4.5.8**。

| 功能 | 单人 | 自己主持的本机多人房间 |
| --- | --- | --- |
| 扫描、命名、箱内整理、跨箱归类、撤销 | 支持 | 由已接入的本机主机执行 |
| 自动存入背包物资 | 支持 | 暂未启用 |
| 合成目标与材料规划 | 支持 | 支持 |

多人自动存包涉及客户端与服务端双份库存，当前未实现断连恢复事务，因此按钮和底层接口均禁用。箱子整理不受此限制。

整理前的完整备份要求角色和世界位于本地。使用 Steam 云存档时，需先在游戏中移出云端。即时撤销与存档备份是不同的恢复方式；恢复存档仍需先正常退出游戏。

更新后，请正常保存退出旧版启动的游戏，再用新版工坊启动。旧版预设、书签和快捷操作会保留。
