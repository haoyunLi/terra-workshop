# 验证记录

## 已观察到的真实游戏行为

- Windows 原版 Terraria 1.4.5.8 可从工坊启动。
- 先前的 `Content/PixelShader.xnb` 路径错误已修复；真实启动日志记录从选择的安装目录读取该资源。
- 游戏生命周期初始化、内容加载、首次更新和桥接连接成功；桌面 UI 显示「游戏已连接，等待进入世界」。

## 自动化验证

- `npm test`：13 项测试，含角色文件工具往返、物品 ID 1–6195 与独立上游读取器交叉验证、配置保存/恢复、备份校验/恢复保护、快捷键注册与冲突处理。
- `npm run build`：生产渲染器构建。
- `npm run test:live`：实际编译的 C# 启动器和桥接器连接自建模拟 API，验证物品发放、槽位编辑/撤销、移除、能力、生命魔力、时间、居民及住房，以及本机请求鉴权。
- 同一集成流程额外启动模拟单人和两个独立的主持客户端/服务端进程，验证主机启动拦截、18 项 Boss 定义（实测眼球、双子、血肉墙与月亮领主调用）、9 类事件启停、物品预设失败回滚、补给、传送边界/碰撞、刷怪倍率和暂停、快捷预设、保存后备份、运行中拒绝恢复，以及挑战前自动备份。

## 界面与桌面验证

- 内置浏览器 `http://127.0.0.1:5175`：1280×720 与 390×844，页面非空、无框架报错、无相关控制台错误，无页面横向溢出。
- 已操作：物品加入快捷栏、创建并发放预设、保存书签、死亡位置与书签之间传送、召唤首领、入侵开始/结束、创建角色与世界备份。
- 原生 Electron 桌面窗口 1536×1024：确认新版页面与本地 IPC 可用；模拟角色生命降低到 70 后，通过真实系统快捷键 `Ctrl+Alt+1` 恢复到 120。
- 所有上述游戏操作使用明确标注的模拟角色/世界，不修改用户的真实存档。
- 对安装的原版 1.4.5.8 客户端和服务端做只读元数据核对：首领/事件方法、存档路径属性、服务器更新循环，以及自然刷怪使用的原生默认字段。

自动化报告将明确标记模拟环境。测试不等于真实游戏中的所有行为都已通过验证。
