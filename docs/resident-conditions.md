# 居民条件的判定范围

泰拉工坊显示的是「自然到访的前置条件」，不是到访倒计时或住房合格证明。已有居民、自然前置条件和强制召唤分别显示。

## 数据来源

已核对本机原版 Terraria 1.4.5.8 客户端的以下元数据和方法控制流；不分发游戏程序集或反编译代码：

- `Main.UpdateTime_SpawnTownNPCs` 的门槛、特殊种子例外和持久解锁字段。这个方法会改变世界，工坊**不调用**它。
- `NPC.SpawnAllowed_Merchant/Nurse/Demolitionist/ArmsDealer/DyeTrader`：只读判定当前在线角色的物品、基础生命及永久解锁标记。
- `Main.GetBestiaryProgressReport`：读取图鉴完成度。

官方 Wiki 用于补充寻找、解救和住房说明：

- [NPCs](https://terraria.wiki.gg/wiki/Townsfolk)：1.4.5 的无房白天到访及夜间离开。
- [Dye Trader](https://terraria.wiki.gg/wiki/Dye_Trader)：染料与人数要求。
- [Party Girl](https://terraria.wiki.gg/wiki/Party_Girl)：1.4.5 人数门槛调整及随机到访。
- [Truffle](https://terraria.wiki.gg/wiki/Truffle)：到访与永久蘑菇住房要求的区别。
- [Town Slimes](https://terraria.wiki.gg/wiki/Town_Slimes)：史莱姆的特殊解锁方式。

## 可核验条件与未知状态

| 条件 | 读取方式 |
| --- | --- |
| 商人、护士、军火商、爆破专家、染料商的角色要求 | 原生只读方法；包含永久解锁例外 |
| 商人钱币门槛 | 在线角色背包钱币合计至少 5,000 铜币；使用游戏判定 |
| 护士和爆破专家需要商人在场 | 当前活动城镇 NPC 列表 |
| 染料商 4、油漆工 8、派对女孩 20 位人数门槛 | 按原生算法统计活动 `townNPC`，包含城镇宠物和史莱姆 |
| 已击败 Boss、已解救、已使用许可证、已解锁史莱姆 | 当前世界的原生布尔字段；字段缺失显示未知 |
| 动物学家 | 图鉴完成度及适用的特殊种子例外 |
| 公主 | 其余 24 位普通居民在场，或永久解锁、适用种子例外；列出缺少居民 |
| 空房、有效家具、腐化、站立点、松露人生物群落 | 未自动扫描，明确显示待确认；安排住房仍由游戏验证 |
| 随机到访、世界时间停止、排队优先级 | 不预测、不修改随机数；前置已满足不保证立即到访 |

覆盖 26 位普通居民、3 种城镇宠物、8 种城镇史莱姆和 2 位特殊访客。特殊访客不显示普通安排住房操作。

## 缓存与多人模式

只在单人世界或本机主机端评估，每 5 秒最多一次；切换世界立即重新评估。UI 显示缓存年龄，NPC 坐标仍来自常规实时快照。多人客户端使用本机主机的同一世界数据；未连接主机、数据来自其他世界时不显示旧条件。

规则目前核验到 `1.4.5.x`。其他游戏版本的前置条件显示未知，不把读取失败当作未满足。房屋查询和原生召唤不作为轮询的一部分，条件评估不会生成 NPC 或更改进度。

「前往居民」使用现有玩家传送命令，附带当前世界 ID，保留坐标范围与碰撞检查；「移到身边」移动的是 NPC。两种操作在 UI 中分别显示。
